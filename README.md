# 📋 TaskFlow - Productivity Dashboard

A modern **To-Do List Web Application** built using **HTML5, CSS3, JavaScript (ES6), and Local Storage API**. The application provides a clean dashboard interface for managing daily tasks with full CRUD functionality and persistent data storage.

---

## 🚀 Project Overview

TaskFlow is a responsive productivity dashboard that helps users organize, track, and manage their daily tasks efficiently. The application stores tasks using the **Local Storage API**, ensuring that data remains available even after refreshing or reopening the browser.

This project was developed as part of the **Novexa Technologies - Full Stack Development Task 3**.

---

- ✅ Add New Task
